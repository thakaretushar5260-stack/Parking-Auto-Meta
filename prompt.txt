### Project Overview & Workflow
1. **RFID Scanning & Login:** User scans an RFID tag at an entry kiosk/terminal. The reader generates/reads a unique Tag ID. The user logs into the Web App using this Unique ID (or registers an account bound to this ID).
2. **Smart Parking Recommendation:** 
   - System checks real-time occupancy.
   - Shows the nearest parking station to the user's current location.
   - If the nearest station is full (100% capacity), automatically recommend the next nearest available parking station.
   - Display exact available slot numbers (e.g., Slot A-02, Slot B-05).
3. **Navigation:** Provide a direct link/button to navigate to the selected parking station via Google Maps (`https://www.google.com/maps/dir/?api=1&destination=LAT,LNG`).
4. **Pre-Booking:** Allow users to pre-book a specific parking slot for a future time slot before arriving.
5. **Check-In / Parking Successful:** When the vehicle enters and parks in the assigned slot, display a "Parking Successful" status.
6. **Check-Out / Slot Release:** When the vehicle leaves (checks out), the system updates the slot status to "Available" immediately across the dashboard.

### System Architecture & Tech Stack

#### 1. Hardware / Embedded (Entry Kiosk & Slot Sensors)
- **Microcontroller:** ESP8266
- **Sensors:** RFID Reader (RC522) D3 & D4, 
	       Ultrasonic Sensors GPIO1 & GPIO 3
	       IR Sensors D0 for individual slot detection.
- **Actuators:** 16x2 LCD with I2C module @0x27 D1 & D2 (shows status, RFID ID, and assigned slot).
- **Barrier Control:** Servo Motor (e.g., SG90 / MG996R) connected to PWM pin D8 (controls gate open/close positions)
- **Network:** WiFi connection sending JSON payloads over HTTP POST/GET to the server.
